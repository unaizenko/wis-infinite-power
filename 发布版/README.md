# WIS-无限战力系统

《WIS-无限战力系统》是一款以WIS战力与量级体系为主题的网页增量游戏。

玩家从普通人开始，自动积累J，通过锻炼将J转化为战力，并逐步跨越爆砖、爆墙、爆屋、爆楼等量级。随着战力提升，新的行动、强化、成就与成长体系会陆续解锁。

[在线游玩发布版](https://unaizenko.github.io/wis-infinite-power/发布版/)

## 主要内容

- 自动获取资源，购买强化并持续提高成长效率。
- 从普通人逐步突破至更高的WIS量级。
- 解锁仙道体系，经历炼气、筑基、结丹及后续境界。
- 收集成就与永久宝物烙印，获得跨轮次成长。
- 通过散功重修重新推进，换取更强的法力成长与境界发展。
- 支持黑白主题、自动保存、存档导入导出与离线收益。

## 游玩方式

直接打开网页即可游玩；也可以下载项目后双击`index.html`在本地运行。

游戏进度保存在当前浏览器中。更换浏览器、设备或网址时，请先导出存档，再在新页面中导入。

## 开发版：离线快进（试用）

设置中的“离线快进（试用）”默认开启，并保存玩家选择。2026-09-11 更新加入下一档法力门槛正向验证、失败跨度记忆和有限帧数退避，减少同一区间反复试算。只有基础 +1 J/s 且满足明确依赖条件的状态采用原 0.1 秒词项精确重复；一般来源仍使用恒定、线性或几何离散模型，并比较整段收益估计与真实端点来源。整段误差估计不等于全局数学误差上界。

化凡、阴虚阳实且无天劫负荷的适用区间可尝试模型快进。修真道按依赖组合开放：稳定仙力采用词项与次数累计，仙力到元力的单向变化接受模型验证；仙体、法则、神通等反馈组合仍走原帧。购买、升级、突破、宝物和挑战完成沿用原事件顺序。其余挑战、未覆盖数值形态及密集事件保留原帧；极高数值无法安全入账时暂停并保留欠账。自动化开关和执行规则不变。高数量宝物的未知余量单独记录，不视为精确零或可消费进度。

恢复弹窗支持暂停并保存、继续／重试，显示待结算游戏时间、最近实际处理倍速和可用的等待估计；速度变化较大时重新估算。进程内回滚点独立保存，在实际保存时编码。固定本次欠账，不补发恢复等待时间，完成后立即恢复在线。正常关闭后产生的新离线时间仍沿用原规则。

当前仅交付已验证的问题修复和部分批量覆盖，完整长离线方案尚未完成。复杂自动化、仙力／元力反馈和密集事件仍有超预算或未完成用例，没有真实玩家存档覆盖。实际耗时、支持范围、数值保护暂停和未实现部分见 [实施验收报告](docs/离线结算-20260911/实施验收报告.md)；固定测试见 [测试说明](tests/offline-20260911/README.md)。各档耗时预算是研发目标，不能视作普遍保证。

## 0.1.5.2 开发版修复

- 每帧在隔离候选状态中计算、检查账本并执行事件，所有步骤成功后保留候选状态。失败恢复资源、统计、时间、宝物、瞬态累加器和随机状态，暂停结算并保留剩余时间。导入和恢复队列也不会额外消耗在线随机状态。
- J、战力、法力、仙灵力统一使用“主值＋有符号补偿＋尾项”。新增、消费、边界投影、重载、重置共用账本规则；扣款失败不再继续授予升级。重复高层仙力以“词项 × 次数”保存，不能安全合并的不同词项达到容量时保留失败帧，不丢弃尾项。
- 动态积分保留 Decimal 边界时间，跨越正常软上限与古戈尔门槛后重算惩罚，并以分段幂律求积和内部采样检查误差。无法在精度预算内完成时暂停，不按旧速率发放剩余区间。
- 导入先完成独立格式检查、迁移、资源和宝物账本校验，再备份并切换。拒绝空对象、无关 JSON 和未来版本；导入中途出错恢复当前进度、离线欠账及原保存内容。启动读档失败时停用自动结算和自动保存，可在设置中导出原文件。
- 转世、散功和挑战等重置保留个性化设置；资源概览下的“资源入账详情”显示完整主值、最近成功入账和补偿词项，区分概览显示位数不足、补偿中累计、手动暂停和异常暂停。
