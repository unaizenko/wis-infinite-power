# WIS-无限战力系统

《WIS-无限战力系统》是一款以WIS战力与量级体系为主题的网页增量游戏。

玩家从普通人开始，自动积累J，通过锻炼将J转化为战力，并逐步跨越爆砖、爆墙、爆屋、爆楼等量级。随着战力提升，新的行动、升级、成就与成长体系会陆续解锁。

[在线游玩发布版](https://unaizenko.github.io/wis-infinite-power/发布版/)

## 主要内容

- 自动获取资源，购买升级并持续提高成长效率。
- 从普通人逐步突破至更高的WIS量级。
- 解锁仙道体系，经历炼气、筑基、结丹及后续境界。
- 收集成就与永久宝物烙印，获得跨轮次成长。
- 通过散功重修重新推进，换取更强的法力成长与境界发展。
- 支持黑白主题、自动保存、存档导入导出与离线收益。

## 游玩方式

直接打开网页即可游玩；也可以下载项目后双击`index.html`在本地运行。

游戏进度保存在当前浏览器中。更换浏览器、设备或网址时，请先导出存档，再在新页面中导入。

## 开发状态

游戏仍在持续开发中，目前主要完成了前期量级、升级、成就、仙道境界、部分仙道能力与宝物烙印内容，其他修行体系和后期WIS体系将在后续版本中继续加入。
