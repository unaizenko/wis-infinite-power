# WIS-无限战力系统

《WIS-无限战力系统》是一款以WIS战力与量级体系为主题的网页增量游戏。

玩家从普通人开始，自动积累J，通过锻炼将J转化为战力，并逐步跨越爆砖、爆墙、爆屋、爆楼等量级。随着战力提升，新的行动、强化、成就与成长体系会陆续解锁。

[在线游玩发布版](https://unaizenko.github.io/wis-infinite-power/发布版/)

## 主要内容

- 自动获取资源，购买强化并持续提高成长效率。
- 从普通人逐步突破至更高的WIS量级。
- 解锁仙道体系，经历炼气、筑基、结丹及后续境界。
- 收集成就与永久宝物烙印，获得跨轮次成长。
- 通过散功重修重新推进，换取更强的法力成长与境界发展。
- 支持黑白主题、自动保存、存档导入导出与离线收益。

## 游玩方式

直接打开网页即可游玩；也可以下载项目后双击`index.html`在本地运行。

游戏进度保存在当前浏览器中。更换浏览器、设备或网址时，请先导出存档，再在新页面中导入。

## 开发状态

游戏仍在持续开发中，目前主要完成了前期量级、强化、成就、仙道境界、部分仙道能力与宝物烙印内容，其他修行体系和后期WIS体系将在后续版本中继续加入。

当前发布版已同步开发版，版本号为 `0.1.5.0`，存档 Schema 为 54，沿用现有旧档迁移。通过本地 `break_eternity.js` 处理持续增长的大数量值；有明确上限的等级、固定系数和时间控制继续使用 Number。发布构建关闭调速及来源调试，页面不包含相应入口。

## 离线快进（试用）

设置中的“离线快进（试用）”默认开启，并保存玩家选择。正常区间根据共享真实帧采样采用恒定、线性或几何离散求和；已覆盖的极高数值终局仍使用原 50 档算法。购买、升级和境界资格沿用原候选，定位门槛后交给原逻辑执行，再重新采样。挑战、天劫负荷、未覆盖数值形态和密集事件使用局部原帧，条件恢复后再尝试快进；不承诺所有状态均已加速。自动化开关、公式和逻辑帧不变。高数量宝物批量模块同时用于在线与离线，未知余量单独记录，不视为精确零或可消费进度。

恢复弹窗支持暂停并保存、继续／重试。固定本次欠账，不补发恢复等待时间，完成后立即恢复在线。正常关闭后产生的新离线时间仍沿用原规则。此功能存在近似误差，不代表原资源 5% 已通过或长期精度已获认证。

本轮备份、测试脚本和结果位于同级的 `../测试/离线快进接入-20260909/`；原 `tests/`、调试报告及旧源码 ZIP 已完整移至 `../测试/WIS-开发版调试-20260909/`，没有删除。开发版运行不依赖测试目录；已生成的 `js/simulation/fast-forward.js` 可直接随网页加载，无需 Node。

详细数值与计算方式见[《数值公式.md》](数值公式.md)。
