# WIS-无限战力系统

页面顶部提供仅用于数值测试的临时调速按钮，可循环切换×1、×5、×20、×100。速度不会写入存档，刷新页面后恢复×1。按钮、样式和交互代码均以“DEBUG SPEED CONTROL”注释标记，删除对应区块后游戏计时会自动回退为正常速度。

资源栏临时显示J、战力和法力的加法来源与独立乘区；J和战力额外显示软上限前后数值，法力显示当前吐纳衰减。相关HTML、CSS和JS均以“DEBUG RESOURCE BREAKDOWN”标记；删除HTML区块即可安全停用，删除三个同名区块可彻底移除。

双击 `index.html` 即可开始游戏，进度自动保存在浏览器中。游戏循环按两次更新之间真实经过的时间计算；浏览器后台降低定时器频率时会自动补足时间差。关闭网页后，存档会记录更新时间，重新打开或导入旧存档时补算离线自动收益，并显示离线时长与所得资源。

离线补算与在线循环共用J、战力、法力和软上限公式。为兼顾动态倍率的准确性与长时间离线的性能，离线时间会被拆分为最多20,000个计算段，而不是直接使用打开页面时的最终速度乘以全部离线秒数；周天产生法力期间的天逆珠判定也会按经过秒数补算。

## 当前规则

- 除非某项内容特别说明，所有加法加成都在乘算前合并并受到适用倍率增益；来自不同系统的倍率属于独立乘区，彼此相乘。
- J与战力软上限读取当前持有数值，不读取每秒或单次增速。爆墙至宇宙结构的各量级阈值均设置软上限；爆墙、爆屋、爆楼较弱，爆街及之后较强。炼气至道祖会按指定对应关系逐层解除爆墙至恒星软上限，星系、超星系团、宇宙结构当前无法解除；J与战力分别计算，法力暂不设置软上限。
- J 会自动获取，非整数数值显示两位小数。
- “锻炼”会将全部 J 转化为基础整数战力，再计算各项倍率和加法加成；基础不足 1 战力时不能进行。
- 获得战力后解锁成就界面；达成“战力 1”后解锁升级界面。
- 健身在获得战力后显示，默认上限 10 级，每级提升自动 J 获取速度；“真爆砖”会把上限提高到 30 级。
- 跑步花费 20 战力，只能升级一次；购买后的倍率会随当前战力持续变化。
- 运动花费 50 战力，只能升级一次；购买后的倍率会随当前 J 持续变化。
- 跑步购买后的基础倍率为 ×1.25，运动购买后的基础倍率为 ×1.10；二者的原成长系数保持不变。
- 集中在爆砖后显示，花费 150 战力且只能升级一次；购买后每秒获得当前锻炼可获得战力的 5%，不会消耗 J。精神力量可将基础比例提高5个百分点，直感再根据当前战力提供动态集中倍率。
- 超凡之力在爆砖后显示，花费 500 战力且只能升级一次；购买后根据当前战力动态提升锻炼获得的战力。
- 极限运动在爆砖后显示，花费1,000战力且只能升级一次；购买后使“运动”的动态J倍率整体提升至1.5倍，未购买运动时不单独生效。
- 达成“爆墙”成就后解锁体系界面，可从仙道、武道、科技、异能、职业者、神秘学中选择；当前仅仙道可选，未来转生后可重置选择。选定后，六种体系选择区会隐藏。
- 仙道内部划分为“境界”和“能力”两个界面；境界已从炼气、筑基、结丹延伸至元婴、化神、炼虚、合体、大乘、真仙、金仙、太乙、大罗、道祖；当前能力仍按已有境界内容分栏。
- 解锁炼气后达成“我欲成仙”；每个已解锁仙道境界提供一个独立的 ×1.2 法力乘区。
- 选择仙道后可消耗10,000战力解锁炼气，同时解锁法力与吐纳；吐纳至少消耗3,000J。法力对自动J的加成使用次线性幂曲线，不再按法力数量线性增长。
- 炼气能力“下品灵根”自动生效，提供×1.1法力乘区，同时使境界突破要求×1.1；筑基基础需求200法力，实际消耗220法力。
- 炼气能力“筑基瓶颈”以原始需求200法力为目标，筑基能力“结丹瓶颈”以原始需求8,000法力为目标。法力越接近对应需求，法力倍率下降越快；完成对应突破后该瓶颈解除。
- 炼气能力“仙道贵生”消耗80法力解锁，使全部战力获取×0.95、法力获取×1.1，二者均为独立乘区。
- 吐纳采用统一的对数幂J曲线，各境界提供独立的吐纳基础值与法力尺度；当前法力越高，吐纳会持续衰减，不再通过不断降低固定幂指数控制。每个未突破的下一境界继续形成当前法力瓶颈。筑基能力“周天”消耗400法力，每秒自动获得当前吐纳收益的8%。
- 筑基能力“法力液化”消耗800法力解锁，使法力获取×0.9、全部J获取×1.15，二者均为独立乘区。
- 筑基能力“延年益寿200载”最多升级2次，两级分别消耗200与600法力；每级使健身等级上限增加10，并使健身效果×1.5。
- 筑基后达成成就“道基”，获得天逆珠的成就资格；还需达成爆屋并解锁宝物界面后才会实际进行判定。
- 结丹基础消耗8,000法力，受下品灵根影响后实际消耗8,800法力，并解锁结丹能力和行动“探寻”。
- 探寻每次固定消耗10,000,000战力，基础获得5,000法力，受到通用法力乘区和神秘绿瓶专属乘区影响。
- 结丹能力“延年益寿400载”最多升级2次，两级分别消耗10,000与40,000法力；每级使健身等级上限增加10，并使健身效果×2。
- 结丹能力“法力固化”消耗16,000法力，使法力获取×0.9、战力获取×1.15，二者均为独立乘区。
- 筑基能力“功法”消耗1,200法力，使法力获取×1.25。结丹能力“法宝”消耗30,000法力，根据当前法力提供通用战力加法。
- 结丹能力“散功重修”最多进行3次；第一次保留普通人升级，第二次保留爆砖及之前升级，第三次保留爆墙及之前升级。行动等级、更高量级升级、J、战力、法力、量级和境界仍会重置；已解锁仙道能力继续显示，成就与宝物烙印永久保留。每次使结丹基础需求×2、元婴基础需求×0.8、法力获取×1.5。
- 结丹能力“天材地宝”只能通过探寻概率升级，初始概率10%，每级后概率×0.75；每级提供×0.1法力倍率加成，最多10级、满级×2。
- 解锁宝物界面且达成“道基”后，天逆珠会在吐纳、周天或探寻获得法力时判定；可重复获得，初始概率1%，每枚使下一枚概率×0.99；每枚使法力倍率增加0.01。
- 结丹后达成成就“一颗金丹吞入腹”；解锁宝物界面后，每次探寻有初始5%概率获得神秘绿瓶，每枚使下一枚概率×0.9，并使探寻法力倍率增加0.05。
- 真爆屋解锁符宝的获取资格；探寻时初始有10%概率获得，每枚使下一枚概率×0.8，并把本次探寻法力的0.5%转化为额外战力。
- 爆墙后解锁行动“打岩”，初始上限10级；基础自动战力按 `40 × 等级^1.4` 增长并受到战力乘区增益。升级消耗J，费用采用平滑的二次增长曲线，真爆墙使上限永久增加20级。
- 爆墙升级栏新增精神力量与生命力量，分别消耗100,000与200,000战力；生命力量使健身倍率×1.5。鬼脑改为根据最高战力提供通用战力加法。
- 爆屋升级栏包含我流、直感、音速移动，分别消耗20,000,000、50,000,000、100,000,000战力；我流根据当前J提升健身倍率，直感根据当前战力提升集中倍率，音速移动使跑步倍率×1.5。
- 爆屋解锁可切换行动“鬼背”；激活时J获取×0.75、战力获取×1.75，关闭后恢复。
- “战五渣”在累计获得 5 战力时达成，使战力转化倍率变为 ×1.05；基础锻炼获得 1 战力时，最终会获得 1.05 战力。
- 当前持有战力达到 200 后进入爆砖量级并永久解锁“爆砖”成就；此后每个已达成成就使自动获取 J 增加 0.1。
- 当前持有战力达到对应阈值后永久进入更高量级；前期量级从普通人延伸至宇宙结构，完整阈值见 `数值公式.md`。
- 达到爆屋后解锁宝物界面，导航顺序为行动、升级、体系、宝物、成就。
- 一次锻炼获得至少 200 战力时解锁“真爆砖”成就，并使健身等级上限提高 20。
- 新成就解锁时会在页面上方显示醒目的成就名称，普通升级不会弹出提示。
- 成就使用独立的永久解锁记录；未来转生即使重置本轮最高战力、累计战力或量级，已经解锁的成就及其奖励仍会保留。设置中的完整重置仍会清空成就。

具体计算方式见 `数值公式.md`。

页面右上角的齿轮按钮可打开设置。设置中可以切换黑/白页面风格、手动保存、导出或导入存档，以及重置游戏。

游戏内主要操作按钮支持长按连续触发。

数值达到1,000后使用`k`，达到1,000,000后使用`M`，达到1,000M（1e9）后使用保留两位尾数的科学计数法。

升级界面按量级分为可折叠栏目：普通人栏目包含跑步、运动；爆砖栏目包含集中、超凡之力、极限运动；爆墙栏目加入精神力量、生命力量；爆屋栏目包含我流、直感、音速移动。

动态倍率类升级在购买前会显示当前可提供的倍率，购买后显示正在生效的当前倍率。

升级界面的千级与百万级消耗分别使用`k`与`m`缩写，例如20,000显示为20k、20,000,000显示为20m；资源栏仍沿用全局数值显示规则。

爆墙至宇宙结构的每个量级均包含普通成就和单次锻炼达标的“真”成就；爆墙成就奖励为解锁体系界面，爆屋成就奖励为解锁宝物界面，其余奖励后续加入。成就页显示已解锁数量与总数，并可隐藏已经解锁的成就。

功能卡片只显示名称，不显示“行动·、升级·、成就·”等定位前缀。

基础数据使用页面横向长栏显示；能够自动获取的数值会在当前值后用括号显示每秒获取量。
